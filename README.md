# AZ-Studio Agency

A stunning, AI-powered web design landing page built with React, Vite, and Tailwind CSS. Featuring smooth animations with Framer Motion and modern UI components.

## 🚀 Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion (`motion`)
- **Icons:** Lucide React
- **Routing:** React Router DOM

## 🛠️ Setup and Installation

Follow these steps to get the project up and running on your local machine.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine. We recommend using `pnpm` as your package manager (as configured in the project), but `npm` or `yarn` will also work.

### 1. Clone the repository

```bash
git clone https://github.com/irfan-za/az-studio-agency.git
cd az-studio-agency
```

### 2. Install dependencies

Using pnpm (recommended):
```bash
pnpm install
```

Or using npm/yarn:
```bash
npm install
# or
yarn install
```

### 3. Run the development server

Using pnpm:
```bash
pnpm run dev
```

Or using npm/yarn:
```bash
npm run dev
# or
yarn dev
```

The application will start, and you can view it in your browser at `http://localhost:5173/`.

## 📦 Building for Production

To create a production-ready build, run:

```bash
pnpm run build
```

This will generate an optimized build in the `dist` folder. You can preview the production build locally using:

```bash
pnpm run preview
```
